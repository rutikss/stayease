# Contributing to StayEase

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/stayease.git`
3. Install dependencies: `npm install`
4. Copy the env file: `cp .env.example .env` and fill in your values
5. Start the dev server: `npm run dev`

## Making Changes

- Create a branch: `git checkout -b feature/your-feature-name`
- Make your changes and test them locally
- Run the linter: `npm run lint`
- Run tests: `npm test`
- Commit with a clear message: `git commit -m "feat: describe what you did"`
- Push and open a Pull Request

## Commit Message Format

| Prefix | When to use |
|---|---|
| `feat:` | New feature |
| `fix:` | Bug fix |
| `chore:` | Maintenance (deps, config) |
| `docs:` | Documentation only |
| `style:` | CSS / formatting |

## Questions?

Open an issue and I'll get back to you.
